# מיילים שבועיים אוטומטיים (יומן משותף)

סקריפט Google Apps Script ששולח כל יום ראשון:

- **07:00 — סיכום שבועי**: מספרי השבוע (נרשמו / תקלות / נסגרו / פתוחים כעת / תקלות פתוחות), פילוח לפי סוג, טבלת אירועי השבוע ורשימת התקלות הפתוחות.
- **08:00 — גיבוי מלא**: קובץ zip ובו JSON של כל היומן והרשימות, באותו פורמט של "הורד גיבוי", כך שאפשר לטעון אותו חזרה באפליקציה.

הסקריפט רץ בחשבון Google של בעל פרויקט ה-Firebase וקורא את Firestore בהרשאות של החשבון הזה. הוא לא דורש תוכנית Blaze ולא שרת נוסף. הקוד לא מכיל שום נתון של האתר: מזהה הפרויקט והנמענים נשמרים ב"מאפייני הסקריפט".

## התקנה (פעם אחת, כ-5 דקות)

1. להיכנס ל-<https://script.google.com> **עם החשבון שבו נוצר פרויקט ה-Firebase** וללחוץ "פרויקט חדש".
2. ⚙️ **Project Settings**:
   - לסמן "Show appsscript.json manifest file in editor".
   - תחת **Script properties** להוסיף:
     | Property | Value |
     |---|---|
     | `PROJECT_ID` | מזהה הפרויקט (מופיע ב-`projectId` בקובץ `firebase-config.js`) |
     | `RECIPIENTS` | כתובות לשליחה, מופרדות בפסיק (אם ריק, המיילים נשלחים לחשבון שמריץ את הסקריפט) |
     | `APP_URL` | אופציונלי: קישור לאפליקציה שיופיע בסיכום |
     | `TITLE` | אופציונלי: כותרת המייל (ברירת מחדל: "יומן אירועים") |
3. בעורך (Editor):
   - להדביק את תוכן `appsscript.json` במקום הקיים.
   - להדביק את `Code.gs` במקום הקוד הקיים.
   - ללחוץ שמירה.
4. לבחור בפונקציה `setup` ולהריץ (▶ Run), ולאשר הרשאות. אם מופיע "Google hasn't verified this app": ללחוץ Advanced ואז Go to…, כי זה הסקריפט שלך.
5. `setup` יוצרת את שני התזמונים ושולחת מיד סיכום אחד וגיבוי אחד לבדיקה.

כדי לשנות נמענים, צריך רק לערוך את `RECIPIENTS`.

כדי לעצור את השליחה: בתפריט ⏰ **Triggers** למחוק את שני התזמונים.

## הערות

- הגיבוי מכיל שמות ותוכן אירועים. כדאי לשלוח אותו רק לכתובות פנימיות.
- Gmail מגביל שליחה ל-100 נמענים ביום בחשבון פרטי, ול-1,500 ביום ב-Workspace. זה הרבה מעבר לצורך כאן.
- אם מופיעה שגיאה "Firestore 403", צריך לבדוק שהסקריפט רץ בחשבון שהוא בעלים או עורך בפרויקט ה-Firebase.
