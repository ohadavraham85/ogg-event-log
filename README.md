# יומן אירועים — מט"ש אוג

יומן רישום אירועים למט"ש אוג: טופס רישום מהיר, רשימות בחירה נערכות, סינון ומיון, ייצוא לאקסל וגיבוי.
האפליקציה רצה כולה בדפדפן — אין שרת ואין בסיס נתונים. היא מותקנת כ-PWA ועובדת גם בלי רשת.

## מבנה הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה הדף: מסך הפתיחה (`#splash`, מוצג בכל פתיחה עד שלוחצים "כניסה"), ארבע הלשוניות (דשבורד — מסך ברירת המחדל / רישום אירוע / אירועים / רשימות וקובץ), חלונית הבחירה, דיאלוג כפילות. טוען את `style.css` ו-`app.js` ורושם את ה-service worker. |
| `style.css` | כל העיצוב: משתני צבע (`:root`), מצב כהה, פריסה למובייל, RTL. |
| `app.js` | כל הלוגיקה (ראו פירוט בהמשך). |
| `manifest.webmanifest` | הגדרות ההתקנה כ-PWA: שם, צבעים, אייקונים, `dir: rtl`. |
| `sw.js` | Service worker — מאפשר פתיחה בלי רשת. |
| `icons/` | אייקון האפליקציה (פנקס עם סמל מבט"י): `icon-notebook.svg` (favicon ומסך הפתיחה), `icon-notebook-192.png`, `icon-notebook-512.png`, `icon-notebook-maskable-512.png` (עם רקע, לאנדרואיד), `icon-notebook-apple-180.png` (עם רקע, לאייפון). הלוגו בראש הדף, עם רקע שקוף: `logo-header.png`. הלוגו המקורי המלא: `logo-mabatei.png`. |

### מה יש ב-`app.js`

הקוד מחולק לפי כותרות `/* ===== ... ===== */`:

- **seed lists** — רשימות הבחירה ההתחלתיות (`SEED`): רק סוגי אירוע וסטטוסים. **מיקומים, ציוד ומעורבים לא נשמרים בקוד**: הרשימות נבנות מהאירועים שבמכשיר, מערכים שנוספו באפליקציה ומגיבויים שנטענו. והגדרות תצוגה (`META`, `HUE`).
- **state** — טעינה ושמירה ל-`localStorage` (`load`, `persist`).
- **טופס הרישום** — חלונית הבחירה, בדיקת כפילויות, שמירה ועריכה.
- **רשימת האירועים** — חיפוש, סינון, מיון, דפדוף ("הצג עוד").
- **ניהול רשימות** — הוספה והסתרה של ערכים; ערך שבשימוש לא ניתן להסרה.
- **הכתבה קולית** — Web Speech API בעברית.
- **file / export** — חיבור לקובץ JSON בתיקייה מסונכרנת (File System Access API), הורדת גיבוי, ייצוא CSV, טעינת גיבוי.
- **version / boot** — מספר גרסה והפעלה.

## איפה נשמרים הנתונים

- **בדפדפן** (`localStorage`):
  - `ogg-log-v2` — האירועים
  - `ogg-lists-v2` — ערכים שנוספו לרשימות או הוסתרו מהן
  - `ogg-theme` — מצב תצוגה (בהיר/כהה)
- **בקובץ JSON** (לא חובה) — דרך "חבר קובץ" או "הורד גיבוי". מבנה הקובץ:
  `{ app, version, saved, events: [...], lists: {...} }`

הנתונים **לא** נשמרים בריפו. `.gitignore` חוסם את כל קבצי ה-`*.json`, כי גיבויים מכילים רישומים אמיתיים ושמות עובדים.

## ה-PWA

- ה-service worker עובד בשיטת **network first**: כשיש רשת האפליקציה תמיד טוענת את הגרסה האחרונה (כך "בדוק עדכון" ממשיך לעבוד כמו קודם). בלי רשת, או כשהאתר מחזיר שגיאה (404 או תקלת שרת), היא מוגשת מהעותק השמור.
- ה-service worker שומר רק את קבצי האפליקציה והגופן, לא את הנתונים.
- שם המטמון (`CACHE` ב-`sw.js`) הוא מספר הגרסה, כך שכל גרסה חדשה מרעננת אותו (ראו "גרסאות").
- ה-service worker עובד רק מ-`https://` או מ-`localhost`. כשפותחים את `index.html` ישירות מהדיסק (`file://`) האפליקציה עובדת, אבל בלי התקנה ובלי מצב לא מקוון.

## הרצה מקומית

```sh
python3 -m http.server 8000
# פתח http://localhost:8000
```

לפרסום מספיק כל אחסון סטטי עם https, למשל GitHub Pages מתוך הענף הראשי.

## גרסאות

**בכל שינוי מעלים את מספר הגרסה**, בשני מקומות:

1. `app.js` — `APP_VER` ו-`APP_DATE`. מהם מתעדכנים התג בכותרת (`v1.9`) והשורה "גרסה" בלשונית "רשימות וקובץ".
2. `sw.js` — `CACHE = "ogg-log-<גרסה>"`, כדי שאפליקציה מותקנת תקבל את הקבצים החדשים.

## היסטוריה

הגרסה המקורית הייתה קובץ אחד, `yoman2.html` (גרסה 1.8). הוא נמצא בהיסטוריית ה-git, ב-commit הראשון.
הפיצול לשלושה קבצים לא שינה את ההתנהגות: אם מחזירים את `style.css` ו-`app.js` לתוך `index.html`, מקבלים את הקובץ המקורי בדיוק, חוץ מתגיות ה-PWA שנוספו.
